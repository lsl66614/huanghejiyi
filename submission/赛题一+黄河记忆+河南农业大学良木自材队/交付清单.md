## 可安装包

`hap/entry-default-signed.hap`（debug 签名，命令行构建 `app/build-oh.bat` 产物）。换机演示需重新生成debug 签名材料，签名私钥与证书**不随包分发**。

## 构建方式

```bat
cd app
build-oh.bat
```

十三道校验在 `assembleHap` 之前执行，任一非 0 即阻断出包；工具链路径可用 `DEVECO_SDK_HOME` / `HUANGHE_NODE` / `HUANGHE_HVIGOR` 覆盖。Node 侧纯函数单测需 Node 24。
