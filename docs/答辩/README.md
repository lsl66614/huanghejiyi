## 一句话记住三条主线

1. **赛题 10 条要求，其中 4 条（#5 #6 #7 #8）都落在同步上** —— 所以底栏第二格必须是「同步」，所以 S6/S7 是技术高点。
2. **裁决逻辑只有一份** —— 仿真与真机共用同一个 `MergeEngine`，换的只是 `ITransport` 实现。
3. **诚实的边界写在明面上** —— T4 冷启动没取到读数就不计入已验证；跨设备时钟偏差修不了就写明。这条是加分项，不是扣分项。
