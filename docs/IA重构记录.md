## 3. 三处逻辑矛盾的消解

1. **「我的」变杂物袋**：网络图、导出并入档案（档案页右上溢出操作），第四格改名「发现」只装推荐 + 路线，版权降级为页脚链接。
2. **「同步是属性却成目的地」**：同步 tab 加**角标**（未裁决冲突数），由 `SyncStatus` 单向镜像到 `AppStorage['syncConflictBadge']`，`AppNavBar` 用 `@StorageProp` 订阅；首页/档案的 `SyncStatusBar` 承担属性常驻，两者不重复。
3. **「档案主语不稳」**：档案页头常驻当前身份（设备 A/B）+ 一句「在同步页切换身份」，把跨 tab 耦合显式化。

## 4. 抽体策略（不复制 UI）

| 页面 | 抽出的体 | 用途 |
|---|---|---|
| FavoritesPage | `export struct FavoritesBody`（`@Prop showNav`） | 档案页「收藏」分段 |
| NoteCenterPage | `export struct NoteCenterBody`（`@Prop showNav`） | 档案页「笔记」分段 |
| RelicListPage | `export struct RelicListBody`（`@Prop embedded`） | 首页「文物」分段（嵌入时隐藏返回键） |

- 三个原页面文件保留兼容壳，但**不再注册路由**（`FavoritesPage` / `NoteCenterPage` 已从 `main_pages.json` 摘除），因为入口已合并；`RelicListPage` 仍注册（ListPage/SearchPage 有入口）。
- 非页面入口组件没有 `onPageShow`，分段切换靠重新挂载触发 `aboutToAppear` 重算——已在各处注释写明。

## 5. 装机实测踩到的坑（已修）

1. **分段计数首帧为 0**：`sites`/`favCount` 是异步填的，`SegmentTab` 的 count 首帧读到 0，屏幕显示「遗址 0」「收藏 0」，与下方内容的真实数字打架。⇒ 分段一律 `count = -1`，计数归内容区。
2. **底栏被正文顶出视口**：`SyncPage` 升频道页后，正文总高超过屏幕，`AppNavBar` 被挤出。⇒ 正文整体包进 `Scroll` 并 `layoutWeight(1)`，底栏留在 Scroll 外。
3. **嵌入的图录挂了「‹ 返回」**：分段不是新压的一页，返回键指向首页自身。⇒ `RelicListBody` 加 `@Prop embedded`，嵌入时隐藏返回键。
4. **a11y 门禁拦下裸符号**：`Text('⇄')` 被判为符号按钮但无读屏标签。⇒ 并入相邻身份文本的 `accessibilityText`。

## 6. 附加规则进 lint

`tools/lint_visual_consistency.py` 新增两条硬规则（防漂回）：

- **未选中态不许上 ACCENT**：判「无条件 ACCENT 描边」（`border` 体内无 `?`）；三元选中态语法合法。`HuangheSeal` 按图形本体豁免（印面就是赭红框，不是状态色）。
- **`borderRadius(0)` 一律禁止**：直角填充块已清零，输入框统一「透明底 + 下沿发丝」。
