## 0. 根因（先读这段，否则会陷入逐页打补丁）

同一个语义在**每个页面各写一遍**。`AppNavBar` 抽成了公共件，所以底栏全站一致；
但卡片、标题、tab、按钮、空态、统计条都是页内私有实现——漂移是必然结果。

⇒ **整改顺序必须是"先抽件、再套用"**，不是逐页微调。逐页改只会产生新的不一致。

### 0.1 最隐蔽的一处：两个赭红并存（能解释"说不出哪儿别扭"）

| 令牌 | 值 | 语义 | 出处 |
|---|---|---|---|
| `ACCENT` | `#9C4A2F` | 全站强调色 | `DesignTokens.ets` |
| `ARCHIVE_PRIMARY` | `#8E4028` | **仰韶年代块色**，被卷宗页当强调色用 | `DesignTokens.ets:50` |

`ARCHIVE_PRIMARY` 与 `EraTheme` 的 `['yangshao', '#8E4028']` **同值**。原注释说"独立出来是为了
将来分色时不动全站强调色"，但代价是：

1. 全站出现两个肉眼几乎分不出、值却不同的红，同步页看着"颜色对但味儿不对"；
2. 把**地层语义色**挪用成 UI 强调色，违反"年代色只表示年代"的既定约束。

⇒ 决策项（二选一，别混着留）：
- **A**：卷宗页统一改用 `ACCENT`，删除 `ARCHIVE_PRIMARY`；
- **B**：若坚持卷宗页独立分色，则改成一个**非年代色**的值，并在 `check_contrast.py` 补校验项。

### 1.1 一条硬约束（本轮两处都栽在这）

> **未选中态一律不许上 `ACCENT`。**
> 未选中 = 白底 + 发丝 + 中性字；选中才上色。
> 违反实例：`NoteCenterPage:310`（标签行未选即赭红描边）、`NoteCenterPage:530`、
> `NotePage:330`、`FavoritesPage:183 / :447`。
> 后果：看着"全被选中了"，真正的选中态反而分不出来。

建议给 `lint_visual_consistency.py` 加一条反向检查：`border` 含 `ACCENT` 且同元素无
`this.xxx === yyy` 条件式者，判 FAIL——否则这类写法会一直漏过门禁。

## 3. 抽件时的技术注意点

### 3.1 全宽卡不能套 `PressScale` / `PressFade`
`StrataSpineCard` 之外的全宽卡，包装器 `Stack` 按内容定宽，会把 `width('100%')`
收成文字宽度。**按压态必须就地写 `onTouch` 三段式**（Down 置位 / Up 与 Cancel 清位）。
`Index.ets` 的文物图录、主题路线两卡已踩过，注释在那儿。

### 3.2 `@Builder` 按值传递，不跟随状态刷新
`SegmentTab` / `StatStrip` 若用 `@Builder`，选中态变化**不会**重渲染。
必须做成独立 `@Component` + `@Prop`（`CabinetCell` 就是这么改的，见其注释）。

### 3.3 `layoutWeight` 在 `@Builder` 调用点不能再续
`this.cell(...).layoutWeight(1)` 报 `Property 'layoutWeight' does not exist on type 'void'`。
写进 @Builder 内部根组件。

### 3.4 禁用态的正确写法（本轮新增，须补进 PITFALLS）
`Button(...).enabled(false)` 会套 ArkUI **系统禁用外观**，把自定义的
`backgroundColor` / `border` / `fontColor` 盖掉，表现为"一块灰斑"。
正解：**不要用 `.enabled(false)`**，改为
`.onTouch` + 一个 `disabled` 布尔态 → 自己降 `opacity` 与字色、**保留描边轮廓**，
`onClick` 内 `if (disabled) return;`。读屏侧配 `.accessibilityText('…，当前不可用')`。
